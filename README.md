IMPORTANT FILE RELATIONSHIPS
- Keep all HTML, CSS, and JavaScript files in the same folder.
- Keep the assets folder beside the HTML files.
- File names and links are case-sensitive on many web hosts.
- If a file is renamed, update every HTML or JavaScript reference to that file.

PUBLISHING ON ANOTHER HOST
This is a static website and does not require a database or server-side program. Upload the full extracted folder to a static website host. The host must treat index.html as the home page and preserve the assets folder.

PRIVACY AND SAFETY
CyberReady processes assessment answers in the visitor's browser. The prototype does not send assessment answers to a database or request passwords, authentication codes, or other sensitive information.
