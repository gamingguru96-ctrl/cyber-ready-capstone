HOW TO EDIT THE WEBSITE
1. Extract the ZIP file to a folder.
2. Open the folder in a code editor such as Visual Studio Code.
3. Edit the HTML files to change page text or structure.
4. Edit styles.css to change colors, spacing, typography, or responsive layouts.
5. Edit assessment.js to change questions, recommendations, or scoring behavior.
6. Open index.html in a web browser to review the website locally.

IMPORTANT FILE RELATIONSHIPS
- Keep all HTML, CSS, and JavaScript files in the same folder.
- Keep the assets folder beside the HTML files.
- File names and links are case-sensitive on many web hosts.
- If a file is renamed, update every HTML or JavaScript reference to that file.

PUBLISHING ON ANOTHER HOST
This is a static website and does not require a database or server-side program. Upload the full extracted folder to a static website host. The host must treat index.html as the home page and preserve the assets folder.

PRIVACY AND SAFETY
CyberReady processes assessment answers in the visitor's browser. The supplied prototype does not send assessment answers to a database or request passwords, authentication codes, or other sensitive information.
