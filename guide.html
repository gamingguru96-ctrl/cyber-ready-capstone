User guide

Using CyberReady safely and effectively

Follow these instructions to complete the assessment, understand the results, and protect sensitive information.

Quick start

Complete the assessment

  1. PrepareUse a trusted device and current browser. Set aside 5 to 10 minutes.
  2. Read the noticeConfirm the assessment is appropriate and do not gather secret values.
  3. BeginSelect Start Assessment to display the first category and question.
  4. RespondChoose Yes, No, or Not sure for every question.
  5. ReviewUse Back and Next to correct responses before selecting View Results.
  6. ActReview the total score, category breakdown, and priority recommendations.
Begin Assessment

Response guide

Choose the most accurate answer

Yes

The practice is consistently in place.

No

The practice is not currently in place.

Not sure

Verification is needed before treating the practice as implemented.

Protect sensitive information. Never enter passwords, authentication codes, encryption keys, financial details, classified information, or controlled unclassified information.

Understanding results

Prototype score bands

Use the score as a directional learning aid. A strong total can still contain an important gap in a specific category.

Score bandMeaningRecommended response
80–100
Strong		Many baseline practices are in place.Maintain safeguards, verify weaker categories, and reassess after major changes.
60–79

General safety

Safe-use requirements

  • Use a trusted device, supported browser, and secure network.
  • Answer at the practice level and never enter or record secret values.
  • Treat “Not sure” as a verification task instead of guessing.
  • Validate recommendations before changing a managed device, account, or network.
  • Never assess systems you do not own or lack permission to review.
  • If you suspect an active compromise, stop and contact the responsible IT or security team.

Technical requirements

Supported environment

Hardware

Minimum 1 GHz dual-core processor, 4 GB RAM, stable internet, and a 720p display larger than 9 inches.

Recommended

Modern quad-core processor, 8 GB RAM, SSD storage, and a display of at least 1366 × 768.

Platforms

Current supported Windows, macOS, ChromeOS, Android, iOS, or iPadOS release.

Browsers

Current Chrome, Edge, Firefox, or Safari. JavaScript must remain enabled.

Troubleshooting

Safe corrective actions

Use the least disruptive correction first. Do not weaken device or browser security controls to resolve a display problem.

The page does not load

Check the internet connection and confirm the address. Retry once. If the problem continues, return later or report the issue to the authorized support contact.

A button does not respond

Wait for the page to finish loading, confirm JavaScript is enabled, and update or restart the browser. Do not disable security controls.

A response is not retained

Return to the question and select the response again. Complete the assessment without refreshing or closing the page.

The mobile layout is difficult to use

Rotate the device, adjust browser zoom, or use a larger supported display. Confirm the browser and operating system are current.

The score seems unexpected

Select Review Answers, check each response, and confirm that “Not sure” was used for any practice that still requires verification.
